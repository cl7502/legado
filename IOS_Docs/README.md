# Legado iOS 版本开发文档

本目录包含 Legado iOS 版本开发相关的所有文档。

## 📁 文档列表

### 📋 [IOS_可行性分析.md](./IOS_可行性分析.md)
**纯 iOS 方案可行性分析报告（v3.0）**

- **项目目标**：打造与 Android 版本完全兼容的 iOS 阅读器
- **核心功能**：书源规则执行、基础阅读、书源管理、内容净化、本地文件阅读、TTS听书
- **技术栈**：Swift 5.9+、SwiftUI、GRDB.swift、Alamofire、JavaScriptCore、SwiftSoup
- **开发周期**：4-5 个月
- **团队规模**：2-3 名 iOS 开发者
