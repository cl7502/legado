# Legado iOS 使用说明书

> 版本：IOS 分支 / 截至 2026-05-30  
> 适用平台：iOS 15.0 及以上

---

## 一、App 功能概览

Legado iOS 是 Android 版 Legado 小说阅读器的 iOS 原生移植版本，完整兼容 Android 版书源格式。主要功能模块如下：

| 模块 | 功能简述 |
|------|---------|
| 书架 | 管理已添加书籍，支持排序、删除、最近阅读优先 |
| 书源管理 | 导入/编辑/检测/调试书源，支持 JSON 与 HTML 规则 |
| 搜索 | 全书源并发搜索，实时展示结果 |
| 发现（Explore） | 按书源分类浏览书单，流式加载 |
| 阅读器 | 分页/滚动双模式，TextKit 2 渲染，含目录/书签/高亮/搜索 |
| TTS 朗读 | iOS 系统语音朗读，支持语速/声音/定时控制 |
| 换源 | 在阅读中切换同书名的不同书源 |

## 二、书架操作

### 2.1 添加书籍

1. 点击底部导航栏「书架」标签进入书架页。
2. 点击右上角搜索图标，在搜索栏输入书名或作者名。
3. 搜索结果列表中点击目标书籍，进入书籍详情页。
4. 点击「加入书架」按钮完成添加。

> 注意：必须先导入至少一个可用书源，搜索才能返回结果。

### 2.2 删除书籍

- 长按书架中的书籍封面，弹出操作菜单，选择「删除」。
- 或进入书籍详情页，点击右上角菜单选择「从书架移除」。

### 2.3 书架排序

书架默认按「最近阅读」时间排序，最新阅读的书排在最前。当前版本不支持手动拖拽排序。

## 三、书源管理

### 3.1 导入书源

支持以下三种导入方式：

**方式 A：粘贴 JSON 文本**
1. 复制书源 JSON 内容（单个对象 `{}` 或数组 `[{},{}]` 均可）。
2. 进入「书源管理」页，点击右上角「+」→「从剪贴板导入」。
3. 确认后批量导入完成，页面显示导入数量。

**方式 B：输入 URL**
1. 进入「书源管理」页，点击「+」→「从 URL 导入」。
2. 输入书源订阅地址，点击「导入」。
3. App 自动下载并解析 JSON，完成后刷新列表。

**方式 C：本地文件**
暂未实现，请使用方式 A 或 B。

### 3.2 书源列表操作

在书源管理列表中，每个书源右侧有三点菜单（`⋯`），提供以下操作：

| 操作 | 说明 |
|------|------|
| 编辑 | 打开书源 JSON 编辑器，可手动修改规则字段 |
| 浏览（Explore） | 进入该书源的发现页，按分类浏览书单 |
| 调试发现规则 | 打开 ExploreDebugView，测试 `exploreUrl` 规则执行结果 |
| 深度检查 | 执行 DeepCheck 流程（详见 3.4） |
| 禁用/启用 | 切换书源启用状态；禁用的书源不参与搜索 |
| 删除 | 永久删除该书源 |
| 排序 | 拖拽调整书源列表顺序 |

### 3.3 书源检测

点击书源管理页右上角「检测」按钮，App 对所有启用书源并发执行连通性检测：
- 依次测试搜索 → 获取书籍详情 → 获取目录 → 获取正文的完整链路。
- 检测结果以绿色（通过）/ 红色（失败）标记显示在列表中。
- 检测完成后可一键删除所有失败书源。

### 3.4 深度检查（DeepCheck）

深度检查对单个书源执行更完整的规则验证：

1. 在书源列表三点菜单中选择「深度检查」。
2. 在配置弹窗（DeepCheckConfigSheet）中设置：
   - 探索步数（默认 5 步）
   - 搜索步数（默认 3 步）
3. 点击「开始检查」，DeepCheckView 实时显示每步执行状态：
   - 探索链路：exploreUrl → 书单解析 → 书籍详情 → 目录 → 正文
   - 搜索链路：searchUrl → 结果解析 → 正文验证
4. 每步显示耗时、状态（成功/失败）和关键结果摘要。

## 四、阅读器操作

### 4.1 进入阅读器

从书架点击书籍封面，或在书籍详情页点击「开始阅读」，进入阅读器（ReaderView）。

### 4.2 翻页模式

阅读器支持两种翻页模式，可在阅读偏好中切换：

| 模式 | 交互方式 |
|------|---------|
| 分页模式 | 点击屏幕左侧区域翻上页，右侧区域翻下页；或左右横滑 |
| 滚动模式 | 上下滑动连续滚动正文 |

### 4.3 阅读器界面（NewLook）

当前 IOS-NewLook 分支的阅读界面布局：

**顶部 Header**
- 左上角：章节导航，显示当前章节号和标题（格式：`‹ 第N章 章节名`），点击返回书籍详情
- 右上角：设置/菜单按钮

**底部 Footer**
- 左下角：自绘电池图标 + 当前时间
- 右下角：当前页码 / 总页数

**工具栏（点击屏幕中央唤出）**
- 目录按钮
- 换源按钮（打开 SourceSelectionView）
- 书签快捷按钮（一键添加书签）
- 朗读按钮（启动 TTS）
- 设置按钮

### 4.4 目录与书签

**目录（TOC）**
- 工具栏点击目录图标，打开 TOCView
- 支持章节搜索，点击章节名跳转

**书签**
- 工具栏点击书签图标，将当前页添加为书签
- 工具栏进入书签列表（BookmarkListView），可查看和跳转所有书签
- 长按书签可删除

### 4.5 高亮划线

1. 长按正文文字，iOS 系统菜单弹出。
2. 选择「高亮」，选中文字变色并保存。
3. 工具栏进入高亮列表（HighlightListView），可查看所有高亮，点击跳转原文。
4. 长按高亮条目可删除。

### 4.6 书内搜索

工具栏点击搜索图标，打开 BookSearchView：
- 输入关键词，搜索当前书籍全部已缓存章节。
- 结果显示章节名 + 上下文片段，点击跳转。

### 4.7 TTS 朗读

**启动朗读**
- 工具栏点击朗读按钮，TTS 从当前段落开始朗读。

**朗读控制面板**
TTS 激活时，底部工具栏变为朗读控制面板，包含：

| 按钮 | 功能 |
|------|------|
| 语速（-/+） | 调慢/加快朗读语速（0.5× ～ 2.0×） |
| 发音人 | 选择 iOS 系统内置语音（支持多语言） |
| 定时停止 | 设置朗读定时关闭（N 分钟后停止） |
| 暂停/继续 | 暂停或继续朗读 |
| 退出朗读 | 停止 TTS，恢复普通阅读工具栏 |

### 4.8 换源

1. 工具栏点击「换源」，打开 SourceSelectionView。
2. App 并发向所有启用书源搜索当前书名，实时展示可用来源列表。
3. 点击目标书源，App 切换书源并保持当前阅读位置（按章节序号匹配）。

## 五、设置说明

### 5.1 访问设置

阅读器工具栏点击设置图标，弹出设置面板（ReaderSettingsSheet），精简为两个标签：

| 标签 | 包含内容 |
|------|---------|
| 字体排版 | 字体大小/行距/段间距/字体选择 |
| 主题 | 内置主题预设 + 自定义背景色/文字色 |

### 5.2 阅读偏好页

从 App 全局设置进入「阅读偏好」，包含更完整的配置：

- **亮度**：独立亮度滑块（不影响系统亮度）
- **布局预设**：页边距/内边距快速预设
- **页眉设置**：显示/隐藏页眉，页眉内容配置
- **高级选项**：翻页动画、点击翻页灵敏度等
- **章节缓存**：预缓存章数设置（并发预缓存下一 N 章）

### 5.3 自定义主题

在设置面板「主题」标签：
1. 点击「自定义」，弹出颜色选择器（iOS 系统 ColorPicker）。
2. 分别设置**背景色**和**文字色**。
3. 自定义主题实时预览，点击保存后立即生效。

## 六、注意事项

### 6.1 已知问题

| 问题 | 描述 | 严重程度 |
|------|------|---------|
| 冷启动延迟 | 首次启动（或重装后）加载耗时 5 秒以上，页面出现迟缓 | 中 |
| 本地文件导入书源 | 暂不支持，需手动复制 JSON | 低 |
| iCloud 同步 | 暂未实现，书架/阅读进度不跨设备同步 | 低 |
| RSS 订阅 | 暂未实现 | 低 |

**冷启动延迟根因**：DatabaseManager 在主线程同步完成数据库迁移（含 10 次迁移状态检查），导致 UI 阻塞。待后续版本迁移至后台线程。

### 6.2 书源兼容性说明

- 支持 Android Legado 标准书源格式（JSON）。
- 支持的规则类型：`@@`（默认）、`@XPath:`、`@Json:`（JSONPath）、`:`（正则）、`<js>...</js>`（JavaScript）。
- 支持 Legado 数字下标语法：如 `a.0@href`、`tag.img.0@src`。
- 支持 `###` 分割多值、`replaceFirst` 替换、JSJavaHelper 全套 API。
- 不支持：需要 Android 原生 API 的书源（如调用系统 Intent 的特殊书源）。

### 6.3 网络与安全

- 所有网络请求通过 Alamofire 发出，支持 Cookie 管理和自定义 Header。
- 部分 JS 规则依赖 HeadlessWebViewLoader（WKWebView 无头模式）加载动态页面。
- 不收集任何用户数据，所有书源和阅读数据仅保存在本地 SQLite 数据库。
