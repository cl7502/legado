## 4. 复杂规则测试

### 4.1 嵌套规则

**HTML 示例**：
```html
<html>
<body>
<div class="book-list">
  <div class="book-item">
    <h3 class="title">Book 1</h3>
    <span class="author">Author 1</span>
  </div>
  <div class="book-item">
    <h3 class="title">Book 2</h3>
    <span class="author">Author 2</span>
  </div>
</div>
</body>
</html>
```

**测试规则**：
```
.book-item@text##Title:\s*(.*?)\s*Author:\s*(.*?)
```

**预期结果**：提取书名和作者

**测试目的**：验证嵌套规则和正则替换

---

### 4.2 JavaScript 复杂规则

**HTML 示例**：
```html
<html>
<body>
<div class="book-list">
  <div class="book-item">
    <h3 class="title">Book 1</h3>
    <span class="author">Author 1</span>
  </div>
</div>
</body>
</html>
```

**测试规则**：
```
<js>
let list = [];
result.select('.book-item').forEach(item => {
  list.push({
    name: item.select('.title').text(),
    author: item.select('.author').text()
  });
});
list;
</js>
```

**预期结果**：返回包含书名和作者的数组

**测试目的**：验证 JavaScript 复杂规则

---

### 4.3 多规则链

**HTML 示例**：
```html
<html>
<body>
<div class="book-list">
  <div class="book-item">
    <a href="/book/1">
      <h3 class="title">Book 1</h3>
    </a>
  </div>
</div>
</body>
</html>
```

**测试规则**：
```
.book-item a@href##/book/(\d+)##https://example.com/book/$1
```

**预期结果**：`https://example.com/book/1`

**测试目的**：验证多规则链和正则替换
